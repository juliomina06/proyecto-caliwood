Proyecto Caliwood - Sistema de Taquilla de Cine
Este proyecto es una aplicación web interactiva desarrollada como parte del curso de Programación III. Simula el sistema de taquilla de un cine, incluyendo módulos de login, venta de boletas, cambio de asientos con recargos, gráficas de recaudación y captura de fotos.
Tecnologías utilizadas: HTML5, CSS3, JavaScript (Vanilla), Chart.js.
Autor: Julio Francisco Mina Advíncula.
