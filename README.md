# Proyecto Caliwood - Sistema de Taquilla de Cine

Este proyecto es una aplicación web interactiva desarrollada para el curso de Programación III. Simula el sistema de taquilla de un cine, incluyendo los módulos de login, venta de boletas, cambio de asientos con recargos, gráficas de recaudación y captura de fotos.

## Funcionalidades
- Login con credenciales (`Cinecali` / `Estrenos`).
- Venta de boletas con cálculo de recaudación y clave de seguridad `CINE`.
- Cambio de asiento con recargo del 5% (3:00 PM - 6:00 PM).
- Gráfica de líneas con Chart.js.
- Captura de foto con la webcam.

## Tecnologías
- HTML5
- CSS3
- JavaScript (Vanilla)
- Chart.js
